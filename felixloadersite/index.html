Features

⚡ Fast Loading

Efficiently loads and executes Lua scripts with minimal overhead

🎯 ValeoHook Support

Built-in integration with ValeoHook for seamless compatibility

📦 Lightweight

Minimal dependencies - just HTML, CSS, and JavaScript

🔧 Easy to Use

Simple API for loading scripts - get started in minutes

Quick Start

-- Basic usage
local loader = require("felix_lua_loader")
loader:loadScript("ValeoHook")

That's it! Your script is now loaded and ready to use.

Installation

  1. Clone the repository from GitHub
  2. Download the Felix Lua Loader files
  3. Include it in your project
  4. Start loading scripts!
